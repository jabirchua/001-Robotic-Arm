# Project 001 — Desktop Robotic Arm

## Overview
Design and development of a desktop programmable robotic arm for electronics work, equipment manipulation, and precision positioning.

## Project Objectives
- Design and build most mechanical components independently
- Support a target payload of 200–500 g
- Achieve a working reach of 25–30 cm
- Provide precise and repeatable positioning
- Explore computer, joystick, and web dashboard control

## Current Phase
Phase 1 — Mechanical requirements and conceptual design.
